CHARU'S BIRTHDAY WEBSITE 💗

YOUR MEDIA IS INCLUDED
- 7 photos: assets/photo1.jpg through assets/photo7.jpg
- 2 videos: assets/video1.mp4 and assets/video2.mp4

OPTIONAL MUSIC
Add a music file named music.mp3 to the assets folder. The visitor must tap the Music button before it can play (phones block autoplay).

PUBLISH WITH GITHUB PAGES
1. Download and extract this ZIP.
2. Open your GitHub repository (or create one).
3. Upload index.html, style.css, script.js, README.txt, and the whole assets folder.
   IMPORTANT: index.html must be at the repository's top level, not inside another folder.
4. On GitHub, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait a little, then open the Pages link shown on that screen.

If media does not show on the live site, check that the file is inside assets and its name matches exactly (capital letters matter).
